# Presse Locale Backend (ppacilyoncentre)

BDD et table dédiées (PresseLocale). Aligné sur l’architecture cppeurope.

- Créer `.env.production` à partir de user-backend : même `JWT_SIGN_SECRET`, `DB_NAME=presse_locale_prod_ppacilyoncentre_v1`, `PORT=7105`, `MEDIA_API_URL`.
- `npm install` puis `node server.prod.js`.
